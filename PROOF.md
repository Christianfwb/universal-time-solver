# Proof, validation and evidence boundary

## Public release and analytical scope

This repository contains the publicly released material on the Frequenzgesetz:
its ontological presentation, mathematical relations and executable examples.

An internal analysis uses the ontology's own definitions, axioms and intended
categories. Silently replacing them with assumptions from another framework and
calling the result an internal refutation is a category error. Internal analysis
can still identify contradictions, undefined terms or invalid deductions within
the stated framework.

External comparisons are explicitly identified as external comparisons. Empirical
assessment concerns observable predictions and reproducible results. These are
different questions from internal coherence; neither is answered by silently
switching between the two. Reproducing a known equation verifies that calculation,
not a new causal interpretation by itself.

Universal Time Solver distinguishes the following layers in the released material.

## 1. Reproducible numerical layer

The package implements established relations:

- Planck relation: **E = hf**
- Mass-energy equivalence combined with Planck's relation: **m = hf/c²**
- Compton frequency: **f = mc²/h**
- Photon energy from wavelength: **E = hc/λ**
- Phase in radians: **T = Δφ/(2πf)**

Tests can verify the implementation and reproduce values derived from the same constants. That demonstrates numerical correctness and internal consistency.

## 2. Exploratory interpretation

Frequency as the causal primary, matter as stabilized oscillation, the cosmic sequence, and the proposed consciousness relation are Christian Berrang's ontological hypotheses. Algebraic rearrangement alone cannot establish causal direction.

## 3. What would count as new evidence?

A strong next step is a preregistered quantitative prediction that differs from a standard model, followed by an independent experiment capable of falsifying it. If changing causal language changes no observable result, the difference remains ontological. If it predicts a new measurable result and survives testing, it becomes empirical evidence.

The examples in this public release document the numerical checks and their scope. See [analytical scope](docs/ANALYTICAL_SCOPE.md) for the distinction between internal analysis and external assessment.
